## Hechos actuales con limitación

- El CSV local contiene 403 episodios, no 403 pinturas originales independientes comprobadas ni la producción artística completa.
- Las 31 temporadas ocurrieron durante 1983–1994 según fuentes externas; el CSV incluye ID de temporada/episodio y NO una columna de fecha exacta de pintura.
- Diagnóstico y última emisión estuvieron temporalmente próximos según prensa; **no existe aún evidencia para una comparación causal de estilo pre/post diagnóstico**.
- La licencia de las etiquetas no constituye permiso de uso de las imágenes.

## Preguntas que aún deben resolverse documentalmente

1. ¿Cuándo se grabaron realmente las temporadas 30–31? ¿Qué episodios se pintaron antes o después del diagnóstico?
2. ¿Qué versiones del cuadro se creaban antes/durante/después de cada rodaje?
3. ¿Existen análisis anteriores de evolución temporal o de temporadas anómalas con los mismos 403 registros?
4. ¿Qué derechos harían posible un inspector hover de pinturas y un eventual video?
5. ¿Qué mecanismo cultural o biográfico, si alguno, tiene soporte suficiente para una hipótesis falsable?
